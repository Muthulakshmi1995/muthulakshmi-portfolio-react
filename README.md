# Muthulakshmi — Personal Portfolio

A responsive React + Vite portfolio with an editorial, photo-led visual design, warm neutral colors, oversized serif typography, project photography, skills, education, achievements, and a contact form.

## Run locally
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown in the terminal (usually http://localhost:5173/).

## Notes
- Project thumbnails use remotely hosted Unsplash images and need an internet connection.
- The contact form opens the visitor's default email application; it does not send messages through a backend.
- The resume button downloads a text profile summary, not a formatted PDF.
- Confirm your contact details and education wording before publishing.
